# ContactsConsoleApp-IntegrationTests

This repository contains integration tests for the `ContactsConsoleAPI` – a console-based .NET application that simulates a contact book system. The goal of the project is to validate core application functionality through properly isolated and reliable tests using NUnit.

## 🧪 Project Overview

The `ContactsConsoleAPI` allows users to manage a contact list through the console. Key operations include:

- Adding a contact
- Deleting a contact
- Listing all contacts
- Updating contact information
- Searching by first or last name

The integration tests are implemented in the `ContactsConsoleAPI.IntegrationTests.NUnit` project, under the file `IntegrationTests.cs`.

## 🛠️ Technologies Used

- .NET Framework
- C#
- NUnit Testing Framework
- Visual Studio

## 🚀 How to Run

To run and observe the results of the integration tests:

1. **Clone the repository:**

2. **Open the solution in Visual Studio.**

3. **Navigate to the test project:**

4. **ContactsConsoleAPI.IntegrationTests.NUnit**

5. **Right-click on the solution and select Run Tests or use the Test Explorer in Visual Studio.**
